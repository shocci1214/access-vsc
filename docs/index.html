Access VSC ドキュメント

Microsoft Access の VBA・クエリ・フォーム・レポートを VS Code で編集し、AI と一緒に開発するための拡張機能 Access VSC の説明書です。目的に合わせて 3 種類あります。

拡張機能 v0.6.0 対応Windows + Microsoft Access
TUTORIAL

チュートリアル

練習用のサンプルを使い、手を動かして小さな改良を 1 本仕上げます。関数を作る → 動かす → 帳票を直す → テスト → AI に頼む、まで一通り体験します。

最初に 1 回 ／ 約 60〜90 分 ／ 上から順に
COURSE

学習コース

初級 → 中級 → 上級の 3 段階。仕組みや考え方を理解し、自分の仕事のデータベースで使いこなせるようになるための教材です。到達目標・演習・理解度チェック付き。

チュートリアルの後 ／ 自分のレベルから少しずつ
REFERENCE

リファレンス

ボタン、コマンド、設定、ファイルの書き方、エラーメッセージ、コマンドライン、AI 用ツールなどの一覧。「あれ、どうだっけ？」のときに引く辞書です。

必要なときに ／ 検索して（Ctrl+F）
