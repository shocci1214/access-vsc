# テストを書いて自動化する

**テストの書き方**（標準モジュールに書きます）

```vb
Public Sub Test_消費税()
    Assert.AreEqual 110, 税込金額(100)
End Sub
```

- 名前が `Test_` で始まる、引数なしの `Public Sub` がテストです
- `TestSetup` / `TestTeardown` があれば各テストの前後に呼ばれます
- テストは **DB のコピー** で動くので、データを書き換えても元の DB は変わりません
- 結果は VS Code の「テスト」ビュー（フラスコのアイコン）に ✔ / ✘ で表示されます

**自動化**

| 仕組み | 内容 |
|---|---|
| 保存時のコードチェック | Shift-JIS にない文字、Option Explicit の書き忘れ、帳票のはみ出しを赤線/黄線で表示 |
| コミット前チェック | エラーがあるとコミットを止めます |
| GitHub Actions | push のたびに lint（クラウド）とテスト（Access 入りの PC）を実行 |
