# Access から取り出す

Access の中身をファイルに書き出します。`app.accdb` なら `app.accdb.src` フォルダができます。

| フォルダ | 中身 |
|---|---|
| `modules` | VBA（標準モジュール `.bas`、クラス `.cls`） |
| `forms` | フォーム（デザインとコード） |
| `reports` | レポート（帳票） |
| `queries` | クエリ（SQL） |
| `tables` | テーブル定義（見るだけ。編集しても反映されません） |

Access の画面で直接変更したときも、もう一度「取り出す」を押すとファイルが最新になります。
