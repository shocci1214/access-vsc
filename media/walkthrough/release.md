# 配布する

| 手順 | 内容 |
|---|---|
| 配布の設定 | アプリ名・配布先の共有フォルダ・本番のバックエンド DB を `access-deploy.json` に保存 |
| リリースを作成 | DB をコピー → 版番号（`AppVersion` プロパティ）を書き込み → リンクテーブルを本番に張り替え → **.accde** を作成 |
| 配布する | 共有フォルダの `app\` を差し替え、`releases\<版>\` に保管、`version.json` を更新 |

**利用者は共有フォルダの `Start-<アプリ名>.cmd` から起動します。**
起動のたびに版を確認し、新しければ自分の PC（`%LOCALAPPDATA%\AccessApps`）にコピーしてから開くので、
全員に配り直す必要はありません。

- 元に戻したいときは「配布する」で `releases` の古い版を選ぶだけです
- アプリの中で版を表示するには `CurrentDb.Properties("AppVersion")`
- `.accde` を開いたときにセキュリティの警告が出る場合は、`%LOCALAPPDATA%\AccessApps` を信頼できる場所に登録するよう管理者に依頼してください
